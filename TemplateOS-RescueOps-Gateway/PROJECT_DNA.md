# PROJECT DNA

## Visão

**TemplateOS RescueOps Gateway** é um gateway documental e operacional para padronizar como incidentes, migrações e fluxos de recuperação são descritos, governados e auditados.

## Eixos de composição

| Eixo | Papel | Escopo nesta fase |
|---|---|---|
| Kaspersky Rescue Disk | Ferramenta externa de recuperação | Referenciada e documentada |
| GitHub | Linhagem, histórico e governança técnica | Estruturas de matriz e catálogo |
| psyDuck | Criptografia/landing | Diretório de módulo criado |
| Emergent | Laboratório de prompts/workflows | Diretório de módulo criado |
| Translado | Migração/transformação | Diretório de módulo criado |
| TemplateOS | Cockpit operacional | Dashboard estático inicial |

## Princípios

1. **Documentação antes de automação**.
2. **Governança explícita de ações permitidas**.
3. **Rastreabilidade por ledger e linhagem GitHub**.
4. **Módulos desacoplados, contratos claros**.

## Não objetivos (fase 0.1.0)

- Integração executável com Kaspersky Rescue Disk.
- Execução real de workflows de resposta.
- Orquestração em produção.
