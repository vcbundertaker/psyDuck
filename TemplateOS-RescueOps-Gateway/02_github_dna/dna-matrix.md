# DNA Matrix

## Matriz de linhagem e acoplamento

| Componente | Tipo | Origem | Dependências | Maturidade |
|---|---|---|---|---|
| TemplateOS RescueOps Gateway | Gateway documental | GitHub | psyDuck, Emergent, Translado | Scaffold |
| Kaspersky Rescue Disk | Ferramenta externa | Vendor (Kaspersky) | Nenhuma (referência documental) | Externo |
| psyDuck | Módulo | GitHub | Governança, Ledger | Planejado |
| Emergent | Módulo | GitHub | Governança, Dashboard | Planejado |
| Translado | Módulo | GitHub | Ledger, Reports | Planejado |

## Convenções de linhagem

- Todo artefato deve ter origem e destino documentados.
- Mudanças de governança exigem atualização do ledger.
- Dashboard deve operar com dados versionados no repositório.
